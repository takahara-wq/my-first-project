保存先：SQLite

prisma/dev.db

選定理由

  • ✓ 無料
  • ✓ 軽量
  • ✓ Cursorで構築しやすい
  • ✓ Vercelと相性が良い
  • ✓ データ永続化の学習に最適
④

工夫したポイント

  • 1. 4ペイン構成で業務画面を再現
  • 2. 顧客→工事→書類の流れを見える化
  • 3. 楽々ライブラリ風の顧客バインダー（棚表示）
  • 4. 色分け・余白で視覚的に理解しやすいUI
⑤

苦戦したポイント

  • ▸ Prisma の設定（スキーマ・Client生成）
  • ▸ SQLite への接続（.env / db push）
  • ▸ データ永続化（Server Actions + revalidate）
  • ▸ 4ペインUIの構築（スクロール・色分け）
  • ▸ Vercel 公開準備（ビルド・環境変数）

データの流れ

顧客選択 → 情報表示 → 工事履歴 → 書類バインダー → SQLite保存
