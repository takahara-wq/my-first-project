API とは何か？

アプリ同士をつなぐ「取り次ぎ窓口」を図解します

① ひとことで言うと（レストランの例）
🙋

（アプリ）
「カレーください」
リクエスト →
⟷
← 料理を持ってくる
レスポンス
🧑‍🍳

（API）
「カレー1つ！」
注文 →
⟷
← 料理を受け取る
🍳
キッチン
（サーバー）

お客さんはキッチンの中に入らなくていい。
ウェイター（API） に頼むだけで、欲しいものが手に入る。
アプリも同じ仕組みでサーバーからデータをもらいます。

③ 通信の4ステップ
1

アプリがリクエストを送る

「天気を教えて」「ユーザー情報をちょうだい」などのお願いをAPIに送ります。
例: GET /weather?city=Tokyo

2

APIがリクエストを確認・振り分ける

「このリクエストは正しい形式か？」「アクセス権限があるか？」を確認して、 サーバーへ適切に転送します。ルールを守った通信のみを通すゲートキーパー。

3

サーバーがデータを処理して返す

データベースからデータを取り出したり、計算をして、APIへ結果を返します。
例: { "city": "Tokyo", "temp": 18 } のようなデータ。

4

APIがアプリへレスポンスを届ける

サーバーから受け取ったデータをアプリに渡します。アプリはそのデータを画面に表示して ユーザーに見せます。「東京 18°C」のように！

④ 身近なAPIの例
🗺️

地図アプリ

Google Maps APIを使って、他のアプリに地図を表示する

🌤️

天気予報

気象庁のAPIから気温・降水確率などのデータを取得する

💳

決済サービス

Stripeなどの決済APIで安全にクレジットカード処理を行う

🤖

AI・ChatGPT

OpenAI APIを呼び出すことで、アプリにAI機能を追加できる

🔐

ログイン連携

「Googleでログイン」ボタンの裏側でOAuth APIが動いている

📦

配送追跡

宅配会社のAPIで荷物の現在地をリアルタイム表示する

📌 まとめ

APIとは 「アプリ同士が会話するための共通ルール」 です。
あなたが作るアプリは、世界中のAPIを呼び出すことで
地図・AI・決済・天気など、あらゆる機能をゼロから作らずに使えます。

APIを使いこなすことが、モダンな開発の第一歩です。
